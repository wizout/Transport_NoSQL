
===== 1. STRING + TTL: кеш інформації про маршрут =====
> SET route:24 '{...}' EX 300
  OK
> GET route:24
  {"number": "24", "name": "Вокзальна - Дарниця", "type": "автобус", "stops": 7, "length_km": 9.5}
> TTL route:24
  300

===== 2. HASH: поточний стан машини =====
> HSET vehicle:AA1234KX route 24 speed 31 passengers 0 ...
  5 машин записано
> HINCRBY vehicle:AA1234KX passengers 7 / -2
  5
> HGETALL vehicle:AA1234KX
  {'route': '24', 'speed': '31', 'passengers': '5', 'updated': '1794346129'}

===== 3. GEO: координати машин і пошук найближчих =====
> GEOSEARCH vehicles:pos FROMLONLAT <Майдан> BYRADIUS 2 km ASC WITHDIST
  [['AA7710KX', 0.1574], ['TR-501', 1.8659]]
> GEODIST stops:pos Вокзальна Лівобережна km
  7.9339
> GEOSEARCH stops:pos FROMMEMBER Університет BYRADIUS 1.5 km
  [['Університет', 0.0], ['вул. Кличка Матьє Болл', 0.8846], ['Вокзальна', 1.2736]]

===== 4. SET: які машини зараз на маршруті =====
> SMEMBERS route:24:vehicles
  {'AA1234KX', 'AA5521KX'}
> SISMEMBER route:24:vehicles T-2201
  0
> SCARD route:24:vehicles
  2

===== 5. SORTED SET: найзавантаженіші зупинки за сьогодні =====
> ZINCRBY stops:boarded:2026-11-09 15 Університет
  110.0
> ZREVRANGE stops:boarded:2026-11-09 0 2 WITHSCORES
  [('Майдан Незалежності', 340.0), ('Лівобережна', 210.0), ('Вокзальна', 120.0)]

===== 6. SET NX EX: захист від повторної оплати (картку прикладають двічі за хвилину) =====
> SET card:1000000101:lock AA1234KX NX EX 60   (перший прохід)
  True -> списуємо гроші
> SET card:1000000101:lock AA1234KX NX EX 60   (через 2 секунди)
  None -> вже оплачено, не списуємо

===== 7. LIST: останні валідації (стрічка для диспетчера) =====
> LPUSH validations:recent ... ; LTRIM validations:recent 0 99
  ok
> LRANGE validations:recent 0 2
  ['1000000103|AA1234KX|3', '1000000105|AA1234KX|2', '1000000102|AA1234KX|1']

===== 8. STREAM: потік телеметрії (потім пачками йде в mongo) =====
> XADD telemetry * plate AA1234KX lat ... speed 31
  3 записи
> XLEN telemetry
  3
> XRANGE telemetry - + COUNT 2
  [('1794346129595-0', {'plate': 'AA1234KX', 'lat': '50.4415', 'lon': '30.495', 'speed': '31'}), ('1794346129595-1', {'plate': 'AA5521KX', 'lat': '50.452', 'lon': '30.56', 'speed': '44'})]

===== 9. INCR: лічильник проходів за день =====
> INCR stats:validations:2026-11-09 (x3)
  3

===== 10. Ключі та видалення =====
> KEYS vehicle:*
  ['vehicle:AA1234KX', 'vehicle:AA5521KX', 'vehicle:AA7710KX', 'vehicle:T-2201', 'vehicle:TR-501']
> DEL vehicle:TR-501
  1
> EXISTS vehicle:TR-501
  0
